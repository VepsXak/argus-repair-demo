# ARGUS-SPECTR — форма заявки в ремонт → Okdesk

Проект состоит из статической формы и маленького Node.js-обработчика. Базы данных нет.

## Что уже работает
- до 30 изделий в одной заявке;
- вложения: JPG/JPEG/PNG/PDF/DOC/DOCX/XLS/XLSX;
- до 10 файлов, до 10 МБ каждый;
- DEMO_MODE: форма реально отправляется на сервер, сервер показывает успех, но Okdesk не затрагивает;
- LIVE_MODE: сервер создаёт заявку через официальный Okdesk API и передаёт вложения.

## Локальный запуск
1. Установить Node.js 18+.
2. В папке проекта выполнить `npm install`.
3. Скопировать `.env.example` в `.env`.
4. Оставить `DEMO_MODE=true`.
5. Выполнить `npm start`.
6. Открыть `http://localhost:3000`.

## Переключение на реальный Okdesk
В `.env`:
- `DEMO_MODE=false`
- `OKDESK_ACCOUNT=argusspectrum`
- `OKDESK_API_TOKEN=...`

API-токен хранится ТОЛЬКО на сервере и никогда не вставляется в HTML/JavaScript браузера.

## Важно перед production
Текущая LIVE-версия создаёт заявку и прикладывает файлы. Контактные данные клиента помещаются в описание заявки. Чтобы Okdesk автоматически связал заявку с существующим/новым контактным лицом и гарантированно запустил ваши клиентские уведомления/личный кабинет, нужно согласовать правило идентификации контакта (обычно e-mail) и права API-ключа. После этого обработчик можно расширить: найти/создать контакт → передать `contact_id` при создании заявки.

Также перед production следует подключить CAPTCHA/антиспам и лимит запросов. Текущая SmartCaptcha штатной формы Okdesk не переносится автоматически в собственную форму.

## Бесплатная демонстрация
Проект подходит для Render/Railway/Fly.io или другого Node.js-хостинга. Для безопасной демонстрации сначала разворачивайте с `DEMO_MODE=true`.
